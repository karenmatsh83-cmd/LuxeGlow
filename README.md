# LuxeGlow Beauty & Cosmetics

## About the Website

LuxeGlow Beauty & Cosmetics is a website proposal for a beauty and cosmetics business. The website provides customers with information about the business, products and ways to make enquiries or contact the business.

## Website Pages

The website contains the following pages:

- Home Page
- About Us
- Products
- Enquiry
- Contact
