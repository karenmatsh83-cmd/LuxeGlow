# LuxeGlow Beauty & Cosmetics

## Part 2 - CSS Styling and Responsive Design

This project is a website for LuxeGlow Beauty & Cosmetics. Part 2 focused on improving the website design using CSS and making the website responsive for desktop, tablet and mobile devices.

## CSS Development

The website uses an external CSS stylesheet called `style.css`. The stylesheet is linked to all five HTML pages.

The CSS includes:

- CSS reset
- Base font and colour styling
- Typography
- Flexbox layout
- Responsive media queries
- Relative units such as rem and percentages
- Borders and box shadows
- Hover, focus and active states
- Responsive images using srcset and sizes

## Responsive Testing

The website was tested using Microsoft Edge Developer Tools at three screen sizes:

### Desktop
1366 × 768

The website was checked for readable text, correct navigation, visible images and suitable spacing.

### Tablet
768 × 1024

The website was checked to make sure the layout adjusted correctly for a medium-sized screen.

### Mobile
375 × 667

The website was checked to make sure the navigation, content, images and product sections fit correctly on a smaller screen.
