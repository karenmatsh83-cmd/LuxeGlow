# LuxeGlow Beauty & Cosmetics

## Project Description

LuxeGlow Beauty & Cosmetics is a website developed to showcase beauty and cosmetic products. The website provides information about the business, displays products and allows visitors to make enquiries.

The project was developed in three parts, focusing on website structure, CSS styling, responsive design, JavaScript functionality and search engine optimisation (SEO).

## Website Pages

The website contains five main pages:

- **Home:** Introduces LuxeGlow Beauty & Cosmetics.
- **About Us:** Provides information about the business, its mission and frequently asked questions.
- **Products:** Displays beauty products with search and sorting features.
- **Enquiry:** Allows visitors to complete an enquiry form.
- **Contact:** Displays contact information and business hours.

## Part 2 - CSS Styling and Responsive Design

Part 2 focused on improving the website design using CSS and making the website responsive for desktop, tablet and mobile devices.

### CSS Development

The website uses an external CSS stylesheet called `Style.css`.

The stylesheet includes:

- CSS reset
- Base font and colour styling
- Typography
- Flexbox layout
- Responsive media queries
- Relative units such as rem and percentages
- Borders and box shadows
- Hover, focus and active states
- Responsive images using srcset and sizes

### Responsive Testing

The website was tested using Microsoft Edge Developer Tools at three screen sizes.

**Desktop:** 1366 × 768

The website was checked for readable text, correct navigation, visible images and suitable spacing.

**Tablet:** 768 × 1024

The website was checked to ensure that the layout adjusted correctly for a medium-sized screen.

**Mobile:** 375 × 667

The website was checked to ensure that navigation, content, images and product sections fitted correctly on a smaller screen.

## Part 3 - JavaScript Functionality and SEO

Part 3 focused on improving website functionality and making the website more search-engine friendly.

### JavaScript Enhancements

A JavaScript file called `script.js` was added to the project.

The following features were implemented:

1. **Dynamic Products:** Product information is displayed dynamically using JavaScript.
2. **Product Search:** Visitors can search for products by name or category.
3. **Product Sorting:** Visitors can sort products alphabetically from A to Z or Z to A.
4. **FAQ Accordion:** Visitors can click questions to display or hide answers.
5. **Image Lightbox:** Visitors can click gallery images to view them in a larger format.
6. **Fade-in Animation:** Website sections display a simple fade-in animation.
7. **Enquiry Form Validation:** JavaScript checks that required fields are completed and that the enquiry message contains at least 10 characters. The browser also validates the email format.

### SEO Improvements

Search Engine Optimisation (SEO) improvements were made to all five website pages.

The improvements include:

- Unique page titles.
- Meta descriptions.
- Relevant keywords.
- Author metadata.
- Proper HTML language declaration.
- Responsive viewport settings.
- Descriptive image alt attributes.
- Appropriate heading structure.

Two additional SEO files were created:

- `robots.txt` - Provides instructions for search engine crawlers.
- `sitemap.xml` - Lists the website pages to help search engines discover them.
